# AGENTS.md — читать первым (любая модель: Claude, GLM, DeepSeek, Kimi, Qwen, Codex…)

Это **конвейер YouTube-видео**: анализ канала → тема → сценарий → самопроверка (халяль, факты) → озвучка → Whisper →
раскадровка и промты → картинки → апскейл → монтаж с анимациями → рендер 2K. Владелец — один человек, пишет по-русски.
Он приходит редко и коротко («сделай 5 видео», «проверь, что не так»), дальше **ты работаешь сам**.

## 0. Старт сессии (каждый раз, 2 минуты)
0. **`docs/AGENDA.md` — датированные проверки каналов: просроченное сделать первым.** Ты — менеджер каналов (`docs/MANAGER.md`),
   статус и просьбы владельца — `docs/ОЧЕРЕДЬ_И_СТАТУС.md` (главнее устаревшего ai/STATUS.md).
1. `python stages.py status` — где каждое видео сейчас (пишет `ai/STATUS_PROJECTS.md`).
2. Прочитай `ai/STATUS.md` (план и что ждёт человека), `ai/LESSONS.md` (грабли — не наступай снова).
3. Возьми **одну** задачу: из сообщения человека, иначе из `ai/BACKLOG.json` (первая с `"done": false`).
4. Работай по циклу из `ai/LOOP.md`. В конце сессии обнови `ai/STATUS.md`, допиши `ai/CHANGELOG.md`,
   новые грабли — в `ai/LESSONS.md`, сделай git-коммит.

## 1. Как общаться с человеком
- По-русски, тепло и коротко («друг»). Без воды и пересказа кода. Итог: что готово, где файл, что нужно от него (1–2 пункта).
- Не спрашивай то, что можно решить самому. Спрашивай только то, что решает он (деньги, публикация, вкус).
- Проверяй результат сам (стоп-кадры, ffprobe, логи), прежде чем сказать «готово».
- Ничего не удаляй из старых версий — переименовывай в `*_old_<дата>`. Не убивай чужие процессы.
- Не коммить/не пушь без просьбы, **кроме** этой папки `conveyor` — здесь коммит в конце каждого цикла разрешён.
- Ключи API (Fish, DeepSeek, GLM…) никогда не печатай и не коммить. Они в `config.json` (в .gitignore) и
  `E:/Adobe/Kanal 2/audio fish/fish_config.json`.

## 2. Главные правила контента (нарушать нельзя)
- **Акида/халяль:** без ширка (вселенная решает, судьба/карма/удача как сила, манифестинг, астрология, гороскопы, магия,
  талисманы), без насмешек над религией, без алкоголя/наркотиков/азарта/рибы/кредитов, без свиданий и романтики как
  крючка, без музыки как идеала, без мата. Полный список — `prompts/rules.md`.
- **Картинки:** все существа с простыми точечными глазами (без детальных глаз), одежда скромная (у женщин закрыты
  плечи/ноги, платок допустим), никаких идолов, зодиака, крестов-символов как объекта поклонения, пар в обнимку.
- **Факты:** только проверяемые; спорное — один честный хедж («возможно», «скорее всего»), дальше уверенно.
  Исследование = автор + год + что сделали + что нашли. Не выдумывать цифры.
- **Монтаж:** камера по картинкам разная и плавная: наезд, отъезд, панорама влево/вправо, наклон вверх/вниз, наезд со
  сдвигом (движок выбирает сам, соседние кадры не повторяются; вручную — `shots[].cam` в edit.json). Одной камеры мало —
  скучно: код-анимации каждые ~15–20 с обязательны. НЕ дрожь, НЕ случайный дрейф, НЕ «boil», НЕ зерно. Подписи читаемые (жирный шрифт на тёмной размытой плашке). Анимации — настоящие, не «текст на картинке».
- **Дизайн свой, не «ИИшный»:** см. `docs/MONTAGE.md` §«Вкус». Не копировать проекты GLM/Z.AI 1:1.

## 4. Какая модель что делает
Конвейер сам вызывает ИИ на этапах (`config.json` → `llm.stages`): по умолчанию Claude через CLI (`claude -p`, по подписке),
любой этап можно переключить на DeepSeek/GLM/OpenAI/Kimi/Qwen (OpenAI-совместимый API, ключ в панели ⚙).
**Ты (агент в чате)** — оператор и инженер: запускаешь этапы, смотришь результат глазами, чинишь, улучшаешь конвейер,
делаешь авторские анимации (HyperFrames). Скиллы: `hyperframes*` (уже стоят в `~/.agents/skills`, `~/.claude/skills`),
наши — в `skills/` (ставит `setup.ps1`). **Перед любой анимацией в HyperFrames загрузи скилл `hyperframes`** и
следуй ему — без скилла слабые модели делают ломаный HTML.

**Если `claude -p` разлогинен** (или нет ключа) — конвейер не встаёт: запрос падает в `ai/inbox/<id>.prompt.md`,
ты отвечаешь файлом `<id>.answer.md` в том формате, что просит промт. Проверку сценария (check) делай строго по пунктам
промта и сверяй КАЖДЫЙ факт; лучше — свежей сессией, а не той, что писала. Длину считай кодом (`stages.words`), не на глаз.
Субагентов на каждый ролик не плоди — лимиты общие.
