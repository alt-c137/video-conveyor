## Как заливать видео (агенту, проверено 04.11)
Studio в Chrome агента; file_upload берёт ≤10 МБ за вызов, локальный сервер страница не видит (Local Network Access висит).
Рабочий способ: `split -b 9500000 -d -a 2 final.mp4 p` в scratchpad → в странице Studio создать свой `<input type=file id=ccpart>`,
по одному file_upload на кусок (48 шт. на 447 МБ) → `new File(parts,'name.mp4')` → DataTransfer в `input[name=Filedata]` + change.
Описание/теги: скопировать out/youtube.md в scratchpad, тем же input, разобрать блоки ``` в JS; `#textbox` [0]=название [1]=описание
(execCommand insertText); «Развернуть» → `input#text-input` теги строкой через запятую + Enter; радио VIDEO_MADE_FOR_KIDS_NOT_MFK;
3× #next-button; «Часовой пояс» → Нью-Йорк; время — пункт списка 15:00; #done-button; OK в окне «Проверка ещё идёт».
