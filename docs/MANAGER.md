# MANAGER — как вести каналы самостоятельно (YouTube-менеджер + конвейер)

Владелец доверил агенту вести каналы целиком: ниши, темы, видео, упаковка, публикация, анализ, правки.
Он приходит редко. Ничего не держать «в голове» — только в файлах ниже, чтобы любой агент в любой сессии продолжил.

## Память (единственные источники правды)
| Файл | Зачем |
|---|---|
| `docs/AGENDA.md` | датированные проверки и дела — открыть первым |
| `docs/ОЧЕРЕДЬ_И_СТАТУС.md` | просьбы владельца, что идёт, что сделано, уроки заливки |
| `docs/TACTICS_LOG.md` | каждое изменение канала: дата / что / почему / цифры ДО / ПОСЛЕ |
| `docs/NEW_CHANNELS_2026-11.md` | 10 новых каналов: ниши, почему, статус |
| `channels/<id>/channel.json`, `BRANDING.md` | ниша, голос, герой, название, описание, лого |
| `docs/montage_library/` | библиотека приёмов монтажа (что можно взять и как) |
| `ai/LESSONS.md` | грабли конвейера |

## Цикл менеджера (каждая сессия)
1. AGENDA: сделать просроченные проверки.
2. Цифры: Studio → Аналитика → explore-таблица (ссылка в `docs/ANALYSIS_BRAND_2026-11-04.md`), для свежего ролика —
   вкладка «Охват» ролика (показы, CTR, источники). Записать в TACTICS_LOG.
3. Решения по правилам (не по настроению):
   - Новое видео: судить не раньше 48 ч. < 300 показов за 48 ч — не трогать, канал ещё не «понят» алгоритмом.
   - CTR < 3 % при 3k+ показов и удержание ≥ 35 % → проблема упаковки: «Тест и сравнение» 3 обложек (не перезаливать).
   - CTR ≥ 5 %, удержание < 25 % → обещание не выполнено: менять начало сценариев следующих видео (хук, первые 30 с).
   - Тема набрала в 2× больше среднего → 2–3 темы-продолжения в topics.json.
   - Одно изменение за раз на ролик, ждать 3–7 дней, записать ПОСЛЕ.
4. Производство: темы → видео по конвейеру (`AGENTS.md`), заливка отложенно 1/день (метод в ОЧЕРЕДЬ_И_СТАТУС).
5. В AGENDA добавить проверки на будущее. Коммит.
