# Картинки: генерация, приём, апскейл

~220–250 кадров на 10 мин (по кадру каждые ~2.5 с), т.е. 330–360 на видео 14–15 мин.

## Формат промта (как у человека)
Одна строка — один промт, номер впереди («187. …»). Шаблон (`stages.py PROMPT_TEMPLATE`, канал может задать свой
`prompt_template` в channel.json с `{loc}` и `{scene}`):
```
N. Flat 2D vector cartoon style, clean uniform black outlines, flat colors, no shading. All characters drawn with the
host's exact technique: same small dot eyes, same simple line mouth, same round head, same outline weight, same flat
colors. Pose each character naturally for the scene, not a static pose. Everyone modestly dressed. LOCATION: <место>.
SCENE: <что происходит>. No text, no captions, no titles. 16:9.
```
- Персонаж-ведущий = **«the host»** (внешность даёт референс — без описания одежды/лица в тексте).
- Женщина: «a young woman in a long beige coat and a light headscarf» (скромно). Остальные — фон, обычные люди.
- Сцена — буквальная картинка того, что звучит; метафоры делать видимыми; 3–5 повторяющихся мотивов на видео.
- Без слов фото/кино (photorealistic, macro, film grain). Без текста на картинке — текст делает монтаж.

## Вариант А — secretslider.com (сейчас основной)
1. Вкладка «Генератор» → режим **«Слайды с 1 персонажем»**.
2. «Персонаж / объект» → файл `E:\Adobe\Канал 5\Референсы и стиль\ава.png` (стиль 1 сохраняется по нему).
3. В поле «Описания картинок» вставить весь `projects/<канал>/<видео>/prompts_lines.txt` (до 500 строк).
4. Сгенерировать, скачать ZIP в `C:\Users\Shoha\Downloads`.
5. Всё. Сервер конвейера раз в минуту смотрит Загрузки: ZIP с кадрами 1..N отдаётся видео, у которого ровно N кадров
   (и которое ждёт картинки). Если два видео с одинаковым N или ZIP неполный — положи ZIP в `<проект>/inbox/`
   или `python stages.py import <проект> <zip>`. Номер кадра берётся из числа в имени файла (12.jpg, slide_012.png…).
Генерация тратит кредиты человека — агент делает её только по его прямой просьбе.

## Вариант Б — Google Flow + расширение Flow Batch Multi (несколько аккаунтов)
- Репо расширения: `E:\Adobe\ilm4\flow-batch-multi` (версия 2.7.0+). Одиночная версия: `E:\Adobe\ilm4\flow-batch-extension`.
- В панели расширения → ⚙ → галочка **«🏭 Конвейер видео»**. Расширение само берёт задание с `http://127.0.0.1:8765/flow/next`,
  делает новый проект Flow в каждом аккаунте, делит промты пачками по 50, качает в `Загрузки/conv_<канал>_<видео>/N.jpg`.
- Лимит Google ≈ 200 генераций на аккаунт в день («подозрительная активность») — расширение даёт аккаунту отдохнуть 4 ч.
- Агент не может перезагрузить расширение сам (chrome://extensions закрыт) — попроси человека.
- Подробности UI Flow: память агента `flow-ui-findings` / README расширения.

## Апскейл
Человек делал в программе Upscayl: модель «цифровое искусство» (digital-art-4x), увеличение ×2 → чуть больше 2K.
Конвейер делает то же из командной строки (этап `upscale`):
```
E:/Adobe/Upscayl/resources/bin/upscayl-bin.exe -i <папка> -o <папка_2x> -m E:/Adobe/Upscayl/resources/models -n digital-art-4x -s 2 -f png
```
Монтаж берёт `images_2x/` (если нет — `images/`). Видео рендерится в 2560×1440.

## Проверка кадров
Перед монтажом: контакт-лист нескольких десятков кадров — номер совпадает с промтом? нет текста? глаза точки?
одежда скромная? Плохие — перегенерировать (номер тот же) или закрыть код-сценой.
