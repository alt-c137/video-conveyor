# ROADMAP — куда растить конвейер (план, не сделано)

Принцип: каждый новый формат = новый **источник визуала** или **слой монтажа**, а не новый конвейер.
Сценарий → озвучка → тайминги → сцены остаются общими; меняется только «чем закрыть кадр».

## 1. Стоковое видео вместо картинок (ниши: история, наука, гео, бизнес)
- Этап `stock`: для каждой строки shotlist — 2–3 поисковых запроса (ИИ) → Pexels / Pixabay API (бесплатные, с лицензией на YouTube).
- **Без аурата:** каждый клип проверяется детектором людей (YOLOv8-pose / MediaPipe, локально на видеокарте).
  Есть открытое тело/неподобающая одежда → берём следующий клип; если других нет — размытие области (OpenCV по маске сегментации).
  Музыкальные клипы, бары, алкоголь, идолы — стоп-слова в запросе + проверка CLIP-классификатором кадра.
- Склейка по смыслу: клип режется под длительность кадра, без ускорений; в монтаже — тот же движок (тип кадра `video`).

## 2. Звуки
- Уже есть: SFX под код-сцены (whoosh/pop/thud…). Дальше: библиотека `assets/sfx/<тег>/` + поиск по тегу из строки сцены
  (дверь, дождь, город, клавиатура) через Freesound API (CC0) с локальным кэшем. Громкость под голос (ducking уже в движке).
- Музыку не добавляем (правило канала) — только звуки окружения и интерфейса.

## 3. Монтаж «как Vox»
- Слои движка: бумажная текстура (статичная, без зерна), вырезанные объекты с тенью, выделение маркером, «доска» с
  пинами и нитками, карты с анимированным маршрутом, газетные вырезки (генерим сами, без чужих логотипов).
- Делается как набор новых типов код-сцен (`engine/src/scenes/`) + правила выбора в `prompts/edit.md`.

## 4. Проект = папка (уже так)
`projects/<канал>/NN_slug/` содержит всё: сценарий, голос, кадры, edit.json, out/final.mp4, out/youtube.md, thumbs/.
Перенос на другой ПК — копировать папку.

## 5. Автозагрузка на YouTube
- YouTube Data API v3 (OAuth на канал пользователя, токен локально в `secrets/`, не в git).
- Этап `upload`: видео как **private/unlisted**, название/описание/теги/главы из `package.json`, превью A,
  плановая дата публикации. Публичным делает человек (решение всегда за ним).
- Квота API ~6 загрузок в день на проект Google Cloud — хватает.

## 6. Веб-приложение
- Сейчас: локальная панель `server.py` (127.0.0.1:8765). Дальше: та же панель + очередь задач + просмотр кадров/превью,
  кнопки «перегенерить кадр N», «другое превью». Облако — только когда понадобится работать с телефона;
  тяжёлое (рендер, whisper, апскейл) всё равно на ПК с видеокартой.

## 7. Экономия кредитов (сделано 2026-10-26)
Код-сцены выбираются до картинок; кадры под ними не генерятся (≈ −50% картинок).
