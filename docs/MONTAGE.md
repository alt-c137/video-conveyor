# Монтаж

Принцип: **ИИ не пишет каждый кадр.** Монтаж описывается данными (`edit.json`), а рисует их готовый движок.
Картинки идут сами (Ken Burns), ИИ только выбирает, ГДЕ и КАКУЮ анимацию поставить и что в ней написать.
Плюс несколько **авторских** вставок на видео (HyperFrames) — там, где шаблона мало.

## 1. Движок (`engine/`, Remotion 4)
- Одна композиция `Video`, вход — `edit.json`. Кадр 2560×1440 (2K), все код-сцены рисуются в 1920×1080 и масштабируются
  (векторно, чётко). 30 fps.
- Слои: картинки (Ken Burns push-in 1.00→1.045, кроссфейд 0.14 с) → код-сцены (заменяют картинку на своё время) →
  виньетка → прогресс разделов → подписи (тёмная размытая плашка) → CTA (подписка/лайк с курсором) → конечная заставка 20 с.
- Голос `public/voice.mp3` (+4.8 дБ, лимитер), SFX без музыки (`engine/sfx/*.wav`, генерирует `engine/gen_sfx.py`).
- Рендер: `node render.mjs <проект>` (GPU `--gl=angle`, concurrency 8, лог `out/render_log.txt`, 15 мин видео ≈ 30–40 мин).
  Стоп-кадры: `node render.mjs <проект> --stills 12 60 300` → `out/check/s_<сек>.jpg`. **Только из PowerShell/Python.**
- Проверка типов после правок движка: `npx tsc --noEmit` в `engine/`.

## 2. edit.json — что можно писать
```
{fps, duration, title, channel, theme{bg,ink,accent,accent2,…}, voice, shots[{src,start,end}], captions[{start,end,text}],
 sections[{start,title}], scenes[{type,start,end,props,cues[]}], sfx[{t,name,vol}], cta{intro,outro}, endSeconds}
```
Типы сцен (props) — каталог для ИИ в `prompts/edit.md`:
title_card, question, quote, words, big_number, list, recap, myth_fact, study, split, cards, bars, dots, scale, iceberg,
meter, curve (dk/rise/decline/u), steps, loop, battery, clock, spotlight, thought (персонаж + мысль), pile, **clip** (готовый mp4).
`cues` — абсолютные секунды появления элементов (= когда голос это говорит, из `words.txt`). Без cues — элементы идут
через ~1 с после начала сцены.
- Этап `edit` сам: делит транскрипт на куски ~4 мин, просит ИИ сцены (одна на ~18 с, ≥10 типов, не подряд одинаковые),
  чистит (2.5–12 с, зазоры, не в первые 3 с раздела), вставляет title_card в начале каждого раздела, CTA по словам
  «subscribe/welcome», подбирает SFX, пишет контакт-лист `out/check_sheet.jpg`. **Посмотри его глазами.**
- `edit_extra.json` — список сцен руками/агентом; главнее автоматических (пересекающиеся авто-сцены выкидываются).
  Пережить пересборку `edit` — только через этот файл.

## 3. Вкус: чтобы не было «ИИшно»
ИИ-монтаж узнаётся по одинаковым карточкам с иконками, неоновым градиентам, «glassmorphism», бесконечным
появлениям «снизу с fade», эмодзи вместо рисунка, тексту-пересказу голоса. Делай наоборот:
- **Один визуальный мотив на видео**, связанный с темой (gray-car: номерной знак как подпись, проезд машины как переход).
  Для sunk cost — квитанции/чеки, для spotlight — луч прожектора, для confirmation bias — лупа/фильтр, для Dunning-Kruger —
  гора и долина, для decision fatigue — батарейка/песочные часы. Мотив повторяется и в финале превращается в вывод.
- **Движение со смыслом:** счётчик реально считает, весы реально перевешивают, толпа из 100 точек реально выделяет 7.
  Не «появилось и висит».
- **Тайминг на слово** (cues), а не равномерно. Пауза в голосе — пауза в анимации.
- **Мало текста:** 1–6 слов, только то, что усиливает (число, имя исследователя + год, ключевое слово).
- Палитра канала спокойная (бумага, тёмный графит, один акцент). Тени мягкие, без неона.
- Персонаж (точечные глаза) появляется в thought/spotlight — он «ведущий», связывает картинки и графику.
- Разнообразие: за видео ≥ 10 типов сцен, 50+ сцен на 15 мин; одинаковые не подряд.
- Нельзя: дрожь/boil картинок, дрейф вбок, зерно, резкие тряски (разве что одна на видео как акцент).

## 4. Авторские вставки через HyperFrames (изюминка)
3–6 на видео: открытие (первые 15 с), кульминация каждого раздела, финальный вывод.
1. **Загрузи скилл `hyperframes`** (и по его маршруту `hyperframes-core`, `hyperframes-animation`, `hyperframes-creative`).
   Скиллы стоят в `~/.agents/skills` и `~/.claude/skills`. Без них не пиши HTML-композиции — получится брак.
   Проверка лимита: `npx hyperframes usage --json`.
2. Композиция 1920×1080, длительность = время сцены (из `words.txt`), без звука, фон/палитра из `edit.json theme`.
3. Рендер в `projects/<канал>/<видео>/clips/<имя>.mp4` (`npx hyperframes render …`, см. скилл `hyperframes-cli`).
4. Добавь в `edit_extra.json`: `{"type": "clip", "start": 123.4, "end": 131.0, "props": {"src": "clips/<имя>.mp4"}}`.
5. `python stages.py edit <проект>` (пересоберёт с вставками) → посмотреть `out/check_sheet.jpg` → `render`.
Эталон качества: `E:\Adobe\Видео ИИ редактор\gray-car-2k` (лучший монтаж по словам владельца; там `ОТЧЁТ_ДЛЯ_ИИ.md`
с 14 граблями). Плейбук: скилл `video-pipeline` → `build_video.md` (режимы «как это видео» / «сделай круто»).

## 5. Перед рендером — чек-лист
- `out/check_sheet.jpg`: все сцены читаются, ничего не обрезано, текст не налезает.
- Кадры без картинок закрыты сценами (лог edit: «нет картинок: N»).
- Подписи не дублируют текст сцены; CTA не перекрывает важную сцену.
- После рендера: `ffprobe out/final.mp4` (длительность = голос + 20 с), 3–4 кадра глазами.
