## 3. Монтаж: креативнее, по смыслу
- После голоса и транскрипта **сначала пишется сценарий монтажа** (этап `montage`, файл `montage.json`), потом монтаж.
- Больше «игры» с видео: по смыслу фразы поверх картинки вылетают/всплывают предметы (говорят про вора — вылетает вор,
  потом мешок денег…), цифры прямо поверх картинки, стоп-кадр (всё серое), обратная перемотка, глитч, вспышка и т.п.
- ВАЖНО: примеры владельца — это иллюстрации принципа, **не делать буквально их везде** (см. память examples-not-literal).
- Скиллы искать через find-skills (`npx skills find <запрос>`); поставлен `remotion-best-practices` (~/.agents/skills).
