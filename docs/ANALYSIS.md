# Анализ канала, план тем, новые ниши

`python stages.py analyze <канал> [кол-во]` (или кнопка «Анализ» в панели):
1. yt-dlp (без API-ключа) берёт видео канала и конкурентов (`channel.json → competitors`) и поиск YouTube по
   `channel.json → search` (что вообще смотрят в нише).
2. Для каждого видео считается **x = просмотры / медиана своего канала**. x ≥ 3 — идея «выстрелила» сама по себе.
   Выбросы конкурентов — главный сигнал спроса.
3. ИИ по `prompts/analyze.md`: диагноз → N тем по порядку публикации (title / safe_title / angle / hedge /
   demand с доказательством / difficulty / minutes / why / series_link) → при N ≥ 10 ещё 3 соседние ниши.
4. Результат дописывается в `channels/<канал>/topics.json` (`topics`, `diagnosis_<дата>`, `niches_<дата>`, `last_analysis`).

## Когда анализ
- `python stages.py status` пишет «НУЖЕН СЕЙЧАС», когда свободных тем < `analysis_every.min_free_topics` (3).
- Автопилот панели делает его сам, если тем не хватает.
- Человек может попросить в любой момент («анализ на 10 видео»).

## Проверки агента после анализа
- Нет дублей с вышедшими видео (`yt_data.json → own.videos`) и с темами в работе.
- Каждая тема проходит халяль-фильтр без оговорок. Сомнительное — удалить, не «смягчать».
- Для «proven» указан реальный ролик-конкурент из данных. Для «white space» — внятная причина.

## Новая ниша / новый канал
Только предложение человеку (1–3 строки: ниша, почему, 3 заголовка, доказательства). Создание канала —
`channels/<id>/channel.json` по образцу `logic_psyche` (name, url, language, niche, audience, format, honesty, voice,
minutes, competitors, search, character, character_w, style_ref, prompt_template?, wpm, analysis_every).

## Конкуренты
Список пока пуст — первым делом при следующем анализе найди 5–10 каналов ниши (по выдаче `search`, где x и просмотры
высокие, faceless/анимация) и впиши их URL в `competitors`.
