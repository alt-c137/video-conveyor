# Рецепт: вертикальный Shorts 30–35 с «Почему X — самое жуткое животное океана?»
(из присланного владельцем промта 06.11; переложено под наш конвейер. Формулы — TECHNIQUES.md)

- 1080×1920, 60 fps, ~115 слов (3.5 слова/с). Единый плоский 2D-стиль: толстый тёмно-коричневый контур #1f1418, плоские цвета,
  простые тени, глаза — У НАС точки (халяль-правило), не «googly».
- Ведущий: молодой мужчина в серой худи без логотипа, с микрофоном, ~1000 px ростом, обрезан по голень, выскакивает снизу за 0.32 с.
  Лицо всегда выше плашки субтитров. Рот — по треку голоса (TECHNIQUES).
- Животное: 9 поз (нейтр., шок, злость + костюмы под факты). Новое место каждые 1.5–3 с, композиции не повторять,
  всегда что-то движется.
- Структура (от 33.5 с): 0–1.9 хук + красное кольцо на имени; 1.9–3.7 наезд на «disturbing» + красный грейд; 3.7–8.2 факт-число
  со счётчиком + понятное сравнение; 8.2–12.7 два факта-гэга; 12.7–15.6 противная деталь с наездом; 15.6–16.7 «But it gets worse»;
  16.7–21 худший факт (рентген); 21–27.7 человеческий угол; 27.7–29 кто-то ест — ведущий зеленеет; 29–33.5 колбэк к хуку.
- Картинки: 4 генерации на ролик (лист животного 3×3, лист реквизита 3×3, сетка 9 фонов 9:16, лист ведущего 9 поз) — каждая с
  «Match the exact art style of the reference image…». В Flow это 4 запроса вместо 40.
- Звук: голос Fish → whisper для таймингов; паузы > 0.2 с срезать до 0.06 с, atempo 1.15. Музыки НЕТ (правило владельца) —
  только SFX: поп на титр, вжух на вход, удар на биты, «пуф». Сведение −14 LUFS.
- Запреты: фото-вырезки рядом с мультом, реальные лица, лого чужих каналов, статичный кадр > 1 с, ведущий закрывает морду животного
  на ключевом слове.
- Применение у нас: Shorts-нарезки для любых каналов + отдельный канал «жуткие факты о животных» (см. NEW_CHANNELS).
