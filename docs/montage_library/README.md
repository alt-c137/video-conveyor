# Библиотека монтажа — что умеем и что можно взять (пополнять после каждого разбора)

Для любого агента: перед монтажом нового канала/формата пролистай этот индекс и возьми 2–4 приёма, подходящих по смыслу
(примеры не правило — `ИИ_ЗАМЕТКИ`). Каждый файл: что это, когда применять, как сделать в НАШЕМ движке (Remotion `engine/`).

| Файл | О чём |
|---|---|
| `TECHNIQUES.md` | Отобранные приёмы (наше + взятое): формулы движения, хост-ведущий с губами, «пружины», грейды, сцены-гэги |
| `SOURCES.md` | Все ссылки владельца/найденные, вердикт: брать / позже / не нужно (и почему) |
| `REVERSE_historically_rome.md` | Разбор «The ENTIRE History of ROME» (Historically, 10M) — что взять для длинных историй |
| `RECIPE_shorts_host_animal.md` | Рецепт вертикального Shorts 30–35 с: ведущий в худи + животное, 9 поз, гэги, формулы |

Уже есть в движке (не изобретать заново): `docs/MONTAGE.md` (сцены D_cinema: morph, sketch, map/globe, donut, funnel, network,
phone, doc, bubbles, stage; 2.5D параллакс rembg; draw-on; переходы zoom/whip/mosaic/cube/iris/wipe; pixelfx для титулов).
