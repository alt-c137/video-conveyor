# Приёмы (отобранные). Формат: приём — когда — как у нас

## Движение (формулы «кадр = функция времени», детерминированно, без дрожи)
- **Pop-появление**: `s = 1 - 0.6·e^(-9Δt)·cos(20Δt)` — объект/герой выскакивает с перелётом. Титулы, предметы.
- **Пинок при смене позы**: `s = 1 + a·e^(-10Δt)·cos(22Δt)`, a = 0.1–0.22. Смена эмоции героя.
- **Удар-тряска**: `dx = A·e^(-7Δt)·sin(61Δt)`, A = 22–34 px, затухает за ~0.4 с. ТОЛЬКО на ударный бит (не дрожь фоном!).
- **Хвост/плавник волной**: картинку резать на 28 вертикальных полос, полоса u: `dy = sin(8t − 4.5u)·wig·k`, `k = (max(0,u−0.3)/0.7)^1.5`, wig 3–14 px.
  Рыбы, флаги, ткань, змеи. В Remotion — 28 `<div>` с background-position.
- **Покачивание** ±10 px синусом медленно (плавание), наезд камеры 2–4 % за план.
- **Слово-титр**: 1–2 слова на бит, наклон ±0.03–0.05 рад, лёгкое покачивание ±0.025 рад, обводка 0.22 размера + тёмная копия цвета
  0.09 размера снизу. Пары цветов: жёлтый #ffd21f/#c27a10, красный #ff4a3d/#8e1a14, белый #fff/#9aa6b4, зелёный #7dff6a/#2e9a2a.
- **Плашка-субтитр** 1–4 слова, ключевое слово жёлтым; появление 0.82→1 за 0.13 с.

## Ведущий-персонаж (хост) с «говорящим ртом» без дрожания контура
- Две позы одинаковые, отличается только рот → совместить шаблоном (глаза/очки), вклеить ТОЛЬКО рот через размытый эллипс (σ 4).
- Трек рта 60 fps из голоса: RMS на кадр, сгладить 3 кадра; открыт, если > (70-й перцентиль дБ − 15) и > 0.55 от пика в ±0.1 с;
  держать состояние ≥ 3 кадра; длинное «открыто» > 14 кадров разбивать закрытием на 3 кадра каждые 12 → ~8 смен в секунду.
- Якорить все позы по ногам и центру головы (центр альфы верхних 28 %) — при смене позы герой не прыгает.
- Наш вариант: ведущий Brand (лысый, худи) / путник Выживания — сделать лист 9 поз в Flow (1 картинка) и резать.

## Вырезка персонажей с белого листа (лист поз 3×3 из одной генерации — 1 кредит вместо 9)
- Заливка белого от краёв (семена каждые 64 px), плавающий допуск 7; полоса 3 px: α = clamp((250 − min(R,G,B))/150),
  снять белый: c' = (c − 255(1−α))/α. Куски группировать по ячейке сетки, < 150 px выкинуть.
- Фоны: сетка 3×3 вертикальных панелей с белыми промежутками → резать по строкам/столбцам со средним min-каналом > 232.

## Грейды (CSS-фильтры в Remotion)
- Тревога/«But it gets worse»: `grayscale(.5) sepia(1) hue-rotate(-35deg) saturate(3.2) brightness(.55)` + пульсирующая виньетка.
  (Сначала sepia, потом hue-rotate — иначе синяя вода зеленеет.)
- Рентген: `grayscale(1) invert(1) sepia(1) hue-rotate(150deg) saturate(3.5)` на #071a2e + циан-сетка 60 px + линия скана.

## Сцены-гэги (вместо «картинка + наезд»)
- Счётчик, который докручивается до шокирующего числа → сравнение «понятное всем» (старше Америки) костюмом/реквизитом.
- Гонка, которую герой проигрывает (ведущий проходит мимо медленного животного).
- «Пуф»-облако — исчезновение; красное кольцо-маркер вокруг объекта, когда его называют.
- Колбэк в финале к хуку + смех ведущего на последнем слове; держать 1.15 с после последнего слова.
