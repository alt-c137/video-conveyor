# Сценарий: чтобы смотрели до конца — и всё халяль и правда

Генерирует этап `script` (`prompts/script.md`), проверяет и правит этап `check` (`prompts/check.md`, `prompts/fix.md`,
до 3 раундов). Ремесло подробно — скилл `skills/youtube-script/SKILL.md` (подключай при ручной работе со сценарием).

## Форма (видео 13–16 мин, ~185 слов/мин)
1. **Крючок 0–15 с.** Продолжает обещание заголовка/превью, а не повторяет его. Конкретная сцена из жизни зрителя +
   неожиданный поворот или цена ошибки. Без «Hey guys, welcome back» в первой фразе.
2. **Обещание удержания (15–40 с):** что зритель унесёт («к концу у тебя будет 3 вопроса, которые…»). CTA на подписку —
   коротко, после того как дали ценность (~30–60 с).
3. **Разделы 3–5** (`[SECTION: …]`), каждый: история/пример → механизм (исследование: кто, год, что сделали, что нашли) →
   как это ломает жизнь → мини-вывод → **микроклиффхэнгер** к следующему разделу («но самое странное — не это…»).
4. **Повторный крючок каждые ~3 мин:** вопрос к зрителю, неожиданный факт, смена масштаба (от одного человека к компаниям).
5. **Практический выход** (обещание канала): 2–4 шага, которые можно сделать сегодня.
6. **Финал:** короткий сильный вывод, связь с мотивом из начала, мягкий CTA + следующее видео канала.

## Язык под ИИ-озвучку и картинки
- Короткие фразы (≤ 28 слов, лучше 8–15), разговорно, «ты/you». Без списков с цифрами «1)», без скобок и сокращений.
- Каждое предложение легко нарисовать: конкретные предметы, места, действия. Повторяющиеся образы-мотивы.
- Числа словами там, где голос может ошибиться. Имена исследователей — как произносятся.

## Фильтры (этап check — блокирующие)
- **Акида:** нет «вселенная/судьба/карма/удача решает», манифестинга, астрологии, магии; ответственность у человека;
  нет насмешек над религией и верующими.
- **Халяль:** нет алкоголя, наркотиков, азарта, рибы/кредитов, свиданий и романтики как примера, музыки как идеала, мата.
  Примеры из жизни — учёба, работа, проект, спорт, семья, друзья, деньги без процентов.
- **Факты:** каждое исследование проверяемо (автор, год, суть). Спорная наука → один хедж (Dunning-Kruger — часть
  эффекта может быть статистическим артефактом; ego depletion плохо воспроизводится). Никаких выдуманных цифр.
- **Механика:** длина ±12 % от цели, без повторов мысли, крючки на месте, нет предложений > 28 слов.
Вердикт check: `ok` / `minor` / `block`. `block` после 3 раундов → видео дальше не идёт, агент разбирается руками.
